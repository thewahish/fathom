No. 16

The Curve Built by Cutting Corners

A Bézier curve looks like it comes from some polynomial formula. It doesn't — it comes from nothing but averaging points on straight lines, over and over, until only one point is left. Drag any amber control point and watch the whole curve reshape itself.

0.00

Connect the control points with straight lines — that dashed cage never changes shape, only where you put its corners. Now pick a fraction t: mark the point that fraction of the way along each segment of the cage (teal), and connect those new points. Do it again — mark the point that same fraction along each of those new segments (indigo). For four control points that leaves one segment, so one more average lands on a single point — and that point sits exactly on the curve. Sweep t from 0 to 1 and that last surviving point traces the whole thing, solid and live, no polynomial ever written down. Drag any amber control point — the curve is rebuilt instantly from the new cage, and it never once wanders outside the cage's own outline. Switch to Quadratic to drop to three points and one round of averaging instead of two: the curve becomes a plain parabola, and you can watch the entire construction collapse to a single color.
