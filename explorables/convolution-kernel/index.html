The Window That Only Ever Sees Nine Pixels

A little 3×3 window slides across a picture. At every stop it can only see the nine pixels directly underneath it — it multiplies each by a fixed weight, adds the nine products, and hands that one number to the output map at that exact spot. Slide it everywhere, reusing the same nine weights every time, and a whole new picture paints itself in.

Every pixel in the left grid is just a number from 0 (dark) to 1 (bright). The nine numbers printed on the amber window are the kernel — fixed weights, one per pixel underneath. At the window's current spot, the machine multiplies each of the nine pixels by the weight sitting on top of it and adds the results into a single number: that's the whole operation, a dot product between nine weights and nine pixels. The window never sees anything outside itself — not the roof, not the door, just whatever nine pixels it's currently sitting on — yet sliding those same nine weights to every position on the picture is enough to build the entire output map on the right. Drag inside the input grid to slide the amber window — the output grid paints in only where you've dragged, one cell at a time, because that's genuinely all the window has reported so far. Switch to vertical edges or horizontal edges and drag along a wall of the house: the output flares teal or indigo exactly where bright meets dark and stays flat and unpainted-looking over flat paint, because subtracting neighboring pixels — which is what those particular nine weights do — is zero wherever nothing changes. Try blur to watch sharp edges melt into averages, or sharpen to watch them get harder. Sweep lets the window visit every position on its own and finish the whole output map.

This is a convolutional layer, run by hand. Real ones stack dozens of these little windows and slide each across the whole image, and none of the nine weights in this machine's presets are hand-picked in a real network — they start out random and get nudged, pixel-grid by pixel-grid, into edge- and texture-detectors purely by training on millions of labeled images, the same slope-following update as gradient descent (No. 10), repeated at enormous scale.
