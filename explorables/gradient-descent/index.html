The Ball That Doesn't Know Where the Bottom Is

Every neural network trains by one rule: feel which way is downhill from right here, take a step, repeat. Drop this ball anywhere on the curve and watch that single rule — not the whole shape, just the slope under its feet — decide where it ends up.

This is gradient descent, run in one dimension so you can watch it happen — the same algorithm that trains almost every machine-learning model that exists. At each step it does exactly one thing: check the slope right under it, and move opposite that slope, scaled by the learning rate. It never sees the whole curve, only the ground under its own feet, which is why where you drop it decides where it lands. Compare f(x) at rest in each valley — one is genuinely deeper — but the ball can't tell that from inside either one. Drag the amber ball to set where it starts, then hit Run. Now push the learning rate up: instead of settling, the ball starts overshooting the bottom, bouncing wall to wall, and past a point it doesn't converge at all — it launches clean off the curve. That's not an exaggeration for effect: a learning rate set too high is one of the most common reasons a real model's training loss explodes instead of shrinking.
